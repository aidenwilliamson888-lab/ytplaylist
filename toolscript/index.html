TMDB → Google Apps Script Generator

This Cloudflare-ready tool generates Code.gs and Index.html files. The generated files can be copied into a Google Apps Script project.

How to use

  1. Fill in the TMDB API key and preferences.
  2. Paste your article containing #TITLE#.
  3. Download the generated files.
  4. Open script.google.com and create a project.
  5. Paste Code.gs into the script editor and create an HTML file named Index.
  6. Paste Index.html, save, and deploy as a Web App.
